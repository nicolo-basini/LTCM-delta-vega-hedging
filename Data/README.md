# Data

The source workbook is not included in the public repository because its redistribution permissions should be confirmed separately.

To run the notebook, place the corrected workbook in this folder using the following filename:

`LTCM_Delta_Vega_Hedging_Corrected.xlsx`

The notebook reads columns A:E from the `Question 3` worksheet, beginning with the header on Excel row 9. The required fields are:

- date;
- VIX;
- S&P 500 index level;
- implied volatility in decimal form;
- continuously compounded interest rate in decimal form.

Before publishing the underlying observations, verify that the original data source permits redistribution. An alternative is to rebuild the dataset from public sources and document the retrieval process.
